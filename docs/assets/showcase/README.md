# Earlier gallery

The project homepage uses the [current eight-figure gallery](v2/README.md).
This directory retains the first set of synthetic examples and their source data.

| Figure | Source | Description |
| --- | --- | --- |
| [UV-vis spectra](uvvis-curves.png) | [CSV](data/curves/uvvis-demo.csv) | Four synthetic curves |
| [Replicate distribution](replicate-distribution.png) | [CSV](data/replicate-demo.csv) | Two samples with three observations each |
| [Performance scatter](performance-scatter.png) | [CSV](data/material-performance-demo.csv) | Six synthetic materials |
| [Radar comparison](performance-radar.png) | [CSV](data/material-performance-radar-demo.csv) | Three metrics with incomplete references |

All figures were rendered by SciPlot / Veusz, then converted from complete PDF
pages to 300 dpi PNG. The data are synthetic demonstrations, not measured material
properties. Demo and Ref names do not identify real samples or publications.

The [requests](requests/) retain the original creation settings.
[SHA256SUMS](SHA256SUMS) records the published image, source and request hashes.
