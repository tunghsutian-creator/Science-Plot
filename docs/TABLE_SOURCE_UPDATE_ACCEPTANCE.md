# Excel 选择与带注释源更新：验收记录

日期：2026-09-10。前两步已有实现和自动化原生流程证据；第三步未完成。
目前没有任何独立原始案例完整通过选择、建图、更新和导出。因此这里不宣称
用户提出的三步完成标准已经全部满足。

后续仅针对科学信息确认的开发已完成一个新增独立原件的建图和导出，见
[科学元数据确认验收](SCIENTIFIC_METADATA_ACCEPTANCE.md)。该结果不包含自然
源修订，因此不改变本文完整“选择—更新—导出”尚未验收的结论。以下表格
保留本轮之前的五份原件及其历史失败证据。

## 已实现的范围

- Excel 原始工作表列表、行列预览、连续数据区域、1–8 行表头、单位行和样品行；
  CSV/TSV 的说明行和不等宽元数据行也走同一选择流程。
- 一个工作表、一个连续区域内的共享 X 和多组 XY，最多 32 对、256 列。
  列索引保留空列位置；样品取所选原始 X/Y 单元格，双方有标签时必须一致。
  一个 XY 对未选择样品行时使用原始文件名。不补填单位、空值或样品名。
- 在原问题上重新回答表格选择可以纠正范围；非法列对不会消耗原问题。
  映射保留原始文件哈希、工作表、元数据单元格和数据行边界。
  原始字节保持不变，派生数据继续由既有 DataMapping 核验。
- 已确认映射项目更新时必须重新选择当前原始列；不复用旧列序号。
  固定注释在新轴范围/单位兼容时保持坐标，数据关联峰按精确样品名和原搜索窗口
  重新计算。移动、消失、多候选、样品缺失或不兼容分别展示。
- 候选图的短 P 编号对应审阅记录中的样品、峰值和 `preview_marker`。
  重绑需要当前候选 ID 与明确的最终文字；也可明确删除或替换为固定注释。
  未解决的候选标记不会被提交。最终图需要新的修订身份才能接受。
- 数据、映射、VSZ 与注释证据经同一源更新事务安装；已安装后的导出失败只重试
  导出。无法证明完成的部分安装仍阻断并保留归档，尚无自动修复承诺。

## 问题、修复与复验

- 多个已选样品原先会作为多个映射文件进入只接收单表的适配器。现由映射 owner
  生成现有三行元数据格式的派生表，并逐字重建验证全部列和样品顺序。
- 保存后导出曾重新解析未选择的原始 Excel。现从已核验的有效映射源恢复计划，
  同时保留并核验真实原件。
- 已映射更新的候选曾缺少安装所需的原始快照。现通过已有 intake owner
  保存同一原件字节，并一并归档/安装。
- 原映射 CSV 的 15 位格式可能截短数值文本。新表格选择使用完整精度输出并增加
  回归；历史映射保留原序列化校验方式，避免旧项目因格式变化失效。
- 峰注释的签名含源文件位置，临时候选转入正式项目后需要重建路径相关证据。
  只有验证原数值、样品、峰和源哈希均未变后才更新该签名。
- 初次原生预览的临时长峰标签碰到图例，改用短 P 编号及对应的数值记录。
- 运行检查发现精度参数与旧故障注入接口不兼容；保留旧调用方式，仅对新表格
  选择传入精度参数。未放宽运行检查。
- 上述修复进入所属模块检查与原生复验。未通过的真实案例继续保持未完成，
  不通过降低科学规则或单位校验来关闭问题。
